# 🛍️ VAYRO — متجر إلكتروني للملابس (E-Commerce Platform)

متجر إلكتروني احترافي وعصري لعلامة تجارية تونسية للملابس (**VAYRO**)، مصمم بأسلوب مينيمالست مستوحى من كبرى الماركات العالمية (مثل Nike)، مع دعم فائق لمحركات البحث (SEO)، سرعة فائقة، وتجربة شراء سلسة عبر WhatsApp.

---

## ✨ المميزات الرئيسية (Core Features)

- **🎨 تصميم مينيمالست وعصري**: مستوحى من علامة Nike، سريع وخفيف ومتجاوب مع جميع الشاشات.
- **⚡ سرعة فائقة و SEO قوي**: مبني باستخدام Next.js (App Router) مع ميزة توليد الصفحات الثابتة (SSG/ISR).
- **📱 إتمام الطلب عبر WhatsApp**: تحويل سلس ومباشر لتأكيد الطلب عبر رسالة WhatsApp منسقة تحتوي على كامل التفاصيل.
- **🌐 دعم متعدد اللغات (i18n)**: واجهة كاملة باللغات الثلاث (العربية 🇹🇳 مع دعم RTL، الفرنسية 🇫🇷، والإنجليزية 🇬🇧).
- **🧊 عرض تفاعلي 3D**: دعم استعراض الملابس بمجسمات ثلاثية الأبعاد (360°) للمنتجات المتوفر لها نموذج، مع معرض صور عالي الدقة.
- **⭐ نظام نقاط الولاء**: كسب نقاط مع كل عملية شراء واستبدالها بخصومات لتشجيع تكرار الشراء.
- **🎟️ كوبونات الخصم (Promo Codes)**: دعم إدخال وتطبيق أكواد الخصم في السلة.
- **🔔 إشعارات "عاد للمخزون"**: تنبيه العملاء عند توفر مقاس أو لون نفد سابقاً.
- **📊 لوحة تحكم ذكية وخفيفة**: مخصصة لصاحب المتجر لإدارة المنتجات، الطلبات، الكوبونات، والمحتوى بسهولة.

## 🛠️ التقنيات المستخدمة (Tech Stack)

| المكون | التقنية |
| :--- | :--- |
| **إطار العمل (Framework)** | [Next.js](https://nextjs.org/) (App Router) |
| **واجهة المستخدم والتنسيق** | [Tailwind CSS](https://tailwindcss.com/) + [Lucide Icons](https://lucide.dev/) |
| **قاعدة البيانات والتخزين** | [Supabase](https://supabase.com/) (PostgreSQL + S3-compatible Storage) |
| **العرض ثلاثي الأبعاد (3D)** | [Three.js](https://threejs.org/) / [@react-three/fiber](https://docs.pmnd.rs/react-three-fiber) |
| **إدارة اللغات (i18n)** | [next-intl](https://next-intl-docs.vercel.app/) |
| **الاستضافة والنشر** | [Vercel](https://vercel.com/) |

## 🚀 البدء والتشغيل محلياً (Getting Started)

### المتطلبات المسبقة:
- [Node.js](https://nodejs.org/) (الإصدار 18 فما فوق)
- مدير الحزم `npm` أو `pnpm`

### خطوات التثبيت:
```bash
# 1. تثبيت الاعتماديات
npm install

# 2. إنشاء ملف المتغيرات البيئية
cp .env.example .env.local

# 3. تشغيل خادم التطوير المحلي
npm run dev
```

افتح المتصفح على: [http://localhost:3000](http://localhost:3000)

## ☁️ النشر على Vercel (Deployment)

المشروع مهيأ للنشر بنقرة واحدة على منصة Vercel:

1. ارفع الكود إلى مستودع GitHub خاص بك.
2. توجه إلى [Vercel Dashboard](https://vercel.com/dashboard) واضغط **"Add New Project"**.
3. اختر مستودع Git الخاص بالمشروع.
4. أضف المتغيرات البيئية (Supabase Keys) في تبويب Environment Variables.
5. اضغط **Deploy** وسيكون الموقع نشطاً ومتاحاً عالمياً برابط مجاني أو دومين مخصص!
